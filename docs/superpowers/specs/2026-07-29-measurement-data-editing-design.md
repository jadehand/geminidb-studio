# GeminiDB Studio Measurement 数据视图与安全写入设计

## 背景

GeminiDB Studio 当前以 SQL 查询窗口为中心。用户在数据目录中单击具体
Measurement 后，客户端会直接改写当前查询页签，生成一条默认查询；查询结果表格
只负责展示，不能在线修改数据。

本次设计解决以下体验问题：

- 批量造数没有出现在新手引导的最后一步。
- 删除连接使用浏览器原生确认框，而不是应用内确认弹窗。
- 查询结果字体偏小，缺少表格缩放能力。
- 客户端拒绝 GeminiDB Influx 支持的 `INSERT` 和 `INSERT INTO`。
- 用户无法像数据库 IDE 一样直接查看具体 Measurement 的原始数据点并修改 Field。

## 用户与核心场景

主要用户是需要查询、补造和修正 GeminiDB Influx 测试数据的研发与测试人员。

核心场景：

1. 从数据目录选择一张具体天表并查看最近的数据点。
2. 在测试或开发环境修正某个数据点的 Field，或为该点补充缺失的 Field。
3. 在查询控制台执行一条或多条自定义 `INSERT`。
4. 在生产环境查看数据，但不能通过客户端发起任何写入。
5. 安全删除本地连接配置，并获得一致的桌面应用交互。

## 设计原则

- SQL 查询结果和可编辑数据视图严格分离。
- 在线编辑只针对客户端可唯一定位的原始数据点。
- 生产环境强制只读，且前端与 Bridge 双重校验。
- 写入操作不伪装成事务；部分成功必须如实呈现。
- 不尝试模拟 GeminiDB Influx 不支持的单 Field 删除或 `NULL`。
- 优先复用现有查询、Schema、页签和结果表格能力，避免无关重构。

## 范围分解

设计分为四个可独立验证的工作流：

1. 数据目录与 Measurement 数据页签。
2. Field 在线编辑与提交。
3. 手工 `INSERT` 与统一环境写入策略。
4. 新手引导、删除确认、结果字体与缩放等体验改进。

实现计划应按此顺序拆分任务。数据页签先具备只读查看能力，再开放在线编辑。

## 数据目录交互

### 节点语义

当前数据目录包含三层节点：

```text
Measurements
└─ cpu_usage                 客户端按名称前缀生成的逻辑分组
   ├─ cpu_usage_1753718400   GeminiDB 中真实的 Measurement
   └─ cpu_usage_1753804800
```

逻辑分组只负责展开和收起。操作菜单只挂在最底层的真实 Measurement 节点上。

### 操作菜单

左键或右键单击具体 Measurement，均打开同一操作菜单：

- 查看数据
- 新建查询
- 查看 Schema

菜单要求：

- 出现在触发位置附近，并保持在可视区域内。
- 点击空白处或按 `Escape` 关闭。
- 支持方向键选择和 `Enter` 执行。
- 不使用双击，避免单击、双击和右键行为冲突。

### 操作结果

“查看数据”打开独立的数据页签；相同连接、Database 和 Measurement 已打开时，
直接切换到现有页签。

“新建查询”创建新的查询页签，不覆盖当前页签。默认 SQL 保持现有行为：

```sql
SELECT *
FROM "measurement"
WHERE time >= now() - 1h
ORDER BY time DESC
LIMIT 100
```

“查看 Schema”复用现有 Schema 弹窗。

## 工作区页签模型

工作区页签扩展为两种类型：

- 查询页签：保留 SQL 编辑器、执行结果、执行记录、收藏和诊断能力。
- 数据页签：展示单个具体 Measurement 的原始数据点，不显示 SQL 编辑器。

数据页签身份由以下信息共同确定：

```text
connectionId + database + measurement
```

数据页签标题使用：

```text
<measurement> · 数据
```

存在未提交修改时，标题显示脏状态标记。

## Measurement 数据视图

### 默认加载

- 时间范围：全天，不追加时间条件。
- 排序：`time DESC`。
- 每页：50 条。
- 每页数量可选：50、100、200、500。
- 使用服务端分页，不一次加载整个 Measurement。

由于目标是具体天表，时间过滤只提供：

- 全天
- 自定义时段

自定义时段必须落在该天表对应日期的 `00:00:00` 到
`23:59:59.999999999` 之间。今天的天表可将结束时间限制为当前时间。

切换时间范围、页码或每页数量前，如果存在未提交修改，必须先走未提交修改保护。

### 行与列

一行代表一个原始数据点。列按以下顺序展示：

1. Time
2. Tags
3. Fields

Bridge 必须保留上游响应中的：

- Measurement 名称
- 完整 Tag 集合
- 原始纳秒时间戳字符串
- Field 值
- Field 类型

不能继续只返回扁平化后的可见列。原始纳秒时间戳必须以字符串保存，不能转换成
JavaScript `number`，避免超过安全整数范围或丢失精度。

### 缺失值显示

某个 Field 在当前数据点不存在时，单元格保持空白，不显示大量 `NULL` 文案。

空白单元格在鼠标悬停或获得键盘焦点时显示轻量编辑提示。空白、缺失值与字符串
空值 `""` 在数据模型中必须严格区分。

## 在线编辑

### 可编辑范围

- 生产环境：数据页签全部只读。
- 测试、开发环境：Field 可编辑。
- Time 和 Tag 在所有环境中只读。
- Schema 中已定义的 Field 即使在当前点缺失，也允许补充值。

在线编辑不支持：

- 修改 Time。
- 修改 Tag。
- 删除单个 Field。
- 把 Field 设置成传统关系型数据库的 `NULL`。
- 跨多个 Measurement 在线编辑。

### 编辑交互

- 双击 Field 单元格进入编辑。
- `Enter` 接受本地修改。
- `Escape` 取消当前单元格编辑。
- 修改后的单元格高亮显示。
- 输入控件按 Schema 类型校验 integer、float、string 和 boolean。
- 数字和布尔 Field 不能提交空输入。
- 字符串 Field 的空输入表示空字符串，而不是删除 Field。

### 写入语义

数据点由以下信息唯一定位：

```text
Measurement + 完整 Tag 集合 + 精确时间戳
```

提交时只写变化的 Field。相同数据点的新旧 Field 集合会合并；同名 Field 使用
新值，未提交的其他 Field 保持不变。

同一数据点修改多个 Field 时，应合并成一次写入。写入编码必须正确处理：

- Measurement、Tag Key、Tag Value 和 Field Key 转义。
- integer 后缀。
- float。
- boolean。
- string 引号与转义。
- 原始纳秒时间戳。

### 工具栏

数据页签工具栏包含：

- 刷新
- 放弃修改
- 提交修改
- 全天/自定义时段
- 每页数量
- 字号缩放

提交按钮使用向上箭头，并显示待提交修改数量，例如：

```text
↑ 提交 3 项修改
```

点击提交即执行，不增加额外确认弹窗，以保持与数据库 IDE 相近的工作流。

### 批量提交与失败处理

提交前按数据点合并修改，然后顺序写入。

任意数据点写入失败后：

1. 立即停止后续写入。
2. 已成功的数据点标记为已提交，并重新读取数据库最新值。
3. 失败项和未执行项保留为待提交状态。
4. 显示成功、失败和未执行数量。

示例：

```text
成功 5 个 · 失败 1 个 · 未执行 3 个
```

GeminiDB Influx 不为这类客户端批量覆盖提供事务，客户端不得宣称自动回滚。

### 未提交修改保护

以下动作发生时，如果存在未提交修改，显示应用内保护弹窗：

- 刷新。
- 翻页。
- 切换时间范围。
- 修改每页数量。
- 关闭数据页签。
- 切换连接或 Database。

弹窗操作：

- 提交
- 放弃
- 取消

## 手工 INSERT

### 支持的命令

查询编辑器增加：

- `INSERT`
- `INSERT INTO`
- 现有 `WRITE`

普通查询逻辑保持不变。

### 多语句执行

支持一次粘贴多条 `INSERT`。执行流程：

1. 正确解析语句边界，不在字符串内容中的分号处分割。
2. 执行前校验全部语句均为允许的写入命令。
3. 显示目标 Database 和语句数量。
4. 用户确认后按顺序执行。
5. 任意语句失败后立即停止。
6. 显示成功、失败和未执行数量。

多语句写入没有事务，也不自动回滚已经成功的语句。

第一版不支持：

- 查询与写入混合脚本。
- 事务语法。
- 失败后继续执行。
- 自动回滚。

## 统一环境写入策略

连接环境成为写权限的唯一策略来源：

- `prod`：强制只读。
- `test`：允许写入。
- `dev`：允许写入。

该策略统一作用于：

- 手工 `INSERT`。
- `INSERT INTO`。
- `WRITE`。
- 批量造数。
- Measurement 数据页签在线编辑。

连接表单中的自由“只读模式”选项改为环境派生状态。生产环境自动只读，测试和
开发环境可写。

前端用于隐藏或禁用写入入口；Bridge 必须独立执行相同检查。即使请求绕过前端，
生产环境写入也返回明确的权限错误。

已有连接迁移时，以 `environment` 为准，不信任旧的 `readOnly` 值。

## 删除连接确认

删除连接改用应用内确认弹窗，不再使用 `window.confirm`。

弹窗内容：

- 连接名称。
- 连接地址。
- “取消”按钮。
- 红色“确认删除”按钮。

行为要求：

- “取消”是默认焦点。
- `Escape` 取消。
- 不增加额外说明。
- 确认后沿用现有本地连接与凭据删除逻辑。

## 查询结果字体与缩放

查询结果和 Measurement 数据页签共用显示设置：

- 默认字号从 10px 调整为 12px。
- 使用清晰的等宽字体栈。
- 提高浅色和深色主题的文字对比度。
- `Ctrl + 滚轮` 按 10% 缩放。
- 缩放范围为 80% 到 160%。
- 工具栏提供 `− 100% +`。
- 点击 `100%` 恢复默认。
- 使用本地存储记住缩放比例。
- 普通滚轮继续负责垂直滚动。

缩放只影响结果表格，不缩放应用其他区域。

## 新手引导

在现有引导最后增加“批量造数”：

- 高亮顶部批量造数入口。
- 介绍选择目标、配置规则、预览后执行的基本流程。
- 不自动打开批量造数窗口。

引导存储版本是否升级应在实施计划中明确。若升级会导致已完成旧引导的用户再次
看到完整引导，应优先只对新用户生效，避免打扰已有用户。

## Bridge API 边界

建议为数据视图提供独立 API，而不是复用只返回扁平 rows 的通用 `/query`：

```text
GET  /measurement-data
POST /measurement-data/updates
```

读取请求至少包含：

- database
- measurement
- page size
- paging cursor or offset
- optional start time
- optional end time

读取响应至少包含：

- rows
- column definitions
- exact point identity
- field types
- paging information

更新请求按数据点提交：

- database
- measurement
- complete tags
- exact timestamp
- changed fields

Bridge 负责最终的环境权限校验、类型编码和写入。前端不直接拼接不受校验的
Line Protocol。

手工 `INSERT` 继续经过命令执行接口，但必须使用服务端命令分类和环境权限校验。

## 错误处理

- 数据查询失败：保留当前页签和筛选条件，允许重试。
- Schema 加载失败：数据页签保持只读，禁止在线提交。
- 输入类型错误：在单元格内提示，不进入待提交集合。
- 会话失效：保留本地修改，重新连接后允许重试。
- 生产环境写入：Bridge 返回稳定错误码，不依赖上游报错文本。
- 部分写入：展示精确计数，不使用笼统的“提交失败”。
- 刷新后找不到原数据点：标记冲突并要求用户重新加载，不盲目覆盖。

## 并发与一致性

GeminiDB Influx 没有为单点覆盖提供行锁或版本号。本功能采用最后写入者生效的
模型。

为了降低误覆盖：

- 页面保存加载时的原始 Field 值。
- 提交后重新查询受影响的数据点。
- 若重新查询结果与预期不一致，标记为冲突并提示刷新。
- 第一版不实现乐观锁或跨客户端冲突合并。

## 测试策略

### 单元测试

- Measurement 菜单左键、右键、键盘行为。
- 工作区查询页签和数据页签身份与去重。
- 天表时间范围边界。
- 纳秒时间戳字符串保真。
- Field 类型校验和 Line Protocol 编码。
- 缺失 Field 补充。
- 已有 Field 覆盖且其他 Field 不丢失。
- 多项修改按数据点合并。
- 手工多语句解析，包括字符串中的分号。
- 遇错立即停止和结果计数。
- 生产环境写入拒绝。
- 缩放范围、恢复和持久化。

### Bridge 集成测试

- 数据视图返回 Measurement、Tags、Fields 和精确时间戳。
- 测试、开发环境写入成功。
- 生产环境所有写入路径均被拒绝。
- 多条 `INSERT` 部分成功后停止。
- Schema 不可用时拒绝在线更新。

### UI/E2E 测试

- 具体 Measurement 单击和右键打开相同菜单。
- 逻辑分组节点只展开或收起。
- 查看数据、新建查询、查看 Schema 三条路径。
- 空白 Field 可补充但不显示满屏 `NULL`。
- Time 和 Tag 不可编辑。
- 修改、放弃、提交与未提交保护。
- 删除连接确认的默认焦点和 `Escape`。
- 结果字号与 `Ctrl + 滚轮` 缩放。
- 新手引导最后一步定位批量造数入口。

## 非目标

本次不实现：

- 跨 Measurement 在线编辑。
- 修改 Time 或 Tag。
- 删除单个 Field 或数据点。
- 将 Field 设置为 `NULL`。
- 通用 SQL 结果可编辑性分析。
- 事务、自动回滚或失败后继续执行。
- 多用户协作锁。
- 数据批量复制粘贴、CSV 导入或整行新增。

## 验收标准

- 只有具体 Measurement 节点显示三个操作项。
- 数据页签默认展示全天最新 50 个点，并支持当天自定义时段与分页。
- 数据页签保存完整点身份和纳秒时间戳。
- 测试、开发环境可修改或补充 Field。
- 生产环境所有写入路径被 Bridge 拒绝。
- 多项提交和多条 `INSERT` 遇错立即停止，并准确显示部分成功。
- 删除连接使用应用内确认弹窗。
- 查询结果默认更清晰，并支持 80% 到 160% 缩放。
- 新手引导最后一步介绍批量造数。
- 未提交修改不会因刷新、翻页、切换上下文或关闭页签而静默丢失。
