# 轻量个人笔记工作台设计

## 目标

在 GeminiDB Studio 中增加独立的“个人笔记”一级工作区，使用用户首次授权的本地 Markdown 目录。风格借鉴 Obsidian 的深色双栏工作台，但保持数据库工具的轻量边界。

## 第二版范围

- 首次选择并记忆本地 Markdown 目录。
- 左侧目录/搜索/标签，右侧 Markdown 编辑与安全预览。
- 新建、重命名、删除、自动保存 `.md` 笔记。
- 将当前查询保存为 `influxql` 代码块。
- 预览中的 InfluxQL 代码块可放入新查询页签，但绝不自动执行。
- 支持标题、段落、列表、任务列表、表格、代码块和标签。

## 明确不做

关系图、双链与反向链接、插件、模板市场、云同步、复杂附件管理和多人协作。

## 安全边界

- 桌面端命令只访问当前已授权目录。
- 仅允许相对路径和 `.md` 文件；拒绝绝对路径、`..`、符号链接逃逸及超大文件。
- Markdown 预览使用 React 文本节点渲染，不解析原始 HTML，不使用 `dangerouslySetInnerHTML`。
- SQL 联动只创建查询页签，不执行命令。
