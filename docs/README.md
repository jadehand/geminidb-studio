# GeminiDB Studio 文档

本目录区分“当前有效说明”和“历史设计资料”：

- [`architecture/`](architecture/)：当前版本的架构、模块归属和安全 seam。
- [`archive/releases/`](archive/releases/)：旧版本功能规格与开发清单，仅供追溯。
- [`archive/plans/`](archive/plans/)：历史实施计划，不代表当前实现。
- [`archive/specs/`](archive/specs/)：历史设计规格，不代表当前产品策略。

面向使用者的安装、启动、功能和安全说明以仓库根目录 [`README.md`](../README.md) 为准；版本变化以 [`CHANGELOG.md`](../CHANGELOG.md) 为准。

历史文档中的版本、环境限制和待办项可能已经过期。判断当前行为时，应以现行架构文档、代码、测试和用户 README 为准。
